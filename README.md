# SDC486Lab
# Customer Shopping Behavior Analysis Using Machine Learning

## Project Overview

This capstone project analyzes customer shopping behavior using the Instacart Online Grocery Shopping Dataset. The goal is to identify purchasing patterns, segment customers based on shopping behavior, and develop a machine learning recommendation system that provides personalized product recommendations.

The project combines exploratory data analysis, customer segmentation, market basket analysis, machine learning, scenario analysis, and interactive Power BI dashboards to demonstrate how data analytics can support retail decision-making.

---

## Business Questions

This project answers the following questions:

1. What products and product categories are frequently purchased together?
2. Can customers be grouped into distinct shopping segments?
3. Can customer purchasing behavior be used to recommend products?
4. Which customer segment presents the greatest recommendation opportunity?

---

## Project Components

### Exploratory Data Analysis (EDA)

- Data cleaning and preprocessing
- Missing value analysis
- Customer purchasing behavior
- Product and department analysis
- Data visualizations

### Customer Segmentation

- K-Means Clustering
- Six customer segments identified
- Segment profiling and comparison

### Market Basket Analysis

- Product pair generation
- Frequently purchased product combinations
- Cross-selling opportunities

### Machine Learning

Models evaluated:

- Logistic Regression (Final Model)
- Neural Network (Comparison Model)

Recommendation model developed using customer purchasing behavior and product relationships.

### Scenario Analysis

Business-focused recommendation scenarios including:

- Produce Supply Shortage
- Summer Cookout Promotion
- Holiday Baking Promotion

---

## Power BI Dashboards

The Power BI report contains four dashboards:

### Dashboard 1 – Customer Segmentation Overview

Visualizes customer segments, purchasing behavior, and shopping characteristics.

### Dashboard 2 – Market Basket Analysis

Displays products frequently purchased together across the entire customer population.

### Dashboard 3 – Targeted Product Recommendations

Demonstrates personalized product recommendations for the High-Volume Organic customer segment using the Logistic Regression model.

### Dashboard 4 – Scenario Analysis

Applies recommendation techniques to business scenarios to support merchandising, inventory planning, and promotional strategies.
